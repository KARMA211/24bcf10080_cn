Open System Interconnection (OSI) model

conceptual framework created by International Organization of Standardization (iso) to describe
how data is transmitted across a network using a structured seven - layer architcture .

- divide network communication into seven functional layers 
- assign specific responsibility to each layer 
- promote compatibility btw diff network systems 
- simplify network design , implementation and trouble shooting

PHYSICAL LAYER ->
transmit raw bitstream over physical medium 
    core responsibility -> translates signals into 0's and 1's 
    hardware -> hubs , modem , cables 
    bit synchronization -> ensure sender and reciver are in sync by providing clock signal .
    bit rate controle -> dictate trsnmission speed i.e. no. of bits sent per sec 
    transmission mode -> determine direction of data flow , using models like simple , 
                         half or full duplex 

DATA LINK LAYER -> 
ensure data transfer is error free 
    data packing (framing) -> data packet recived from network layer are divided in frames by 
                            adding specific "start" and "stop" bits 
    adressing and hardware -> uses MAC adresses(physical adress) to identify Host , 
                              encapsulate sender and reciver MAC adress into the frame header 
    sublayers->(one above dll and one below)
      1> Logic Link Controle (LLC): managle flow and error ctrl while acting as an interface for 
                                    upper layer protocol (network layer)
      2> Media Acess Control (MAC): determine hpw device physically access the transmission                          
                                    medium and handle hardware adressing 

    Error Crl -> detect and restransmit damaged or lost frames 

    flow ctrl -> sunchronize data rate btw fast sender and slow reciver to prevent data bottlenecks

    Acsess ctrl -> when multiple device share comm. channel , the MAC sublayer dictates which
                   device has the right to transmit at a given time 


NETWORK LAYER -> 
manage data transmission btw host across diff. networks by handling logical adressing and path finding 

    data unit -> data segments are encapsulated into packets 
    Logical adressing -> assign unique ip to the packet header to the packet header to identify 
                         device globally

TRANSPORT LAYER -> 
ensure end to end delivery of entire message , ensure data reaches the correct application on the 
destinantion port  

    data unit -> data broken in to segments 
    service point adressing -> uses port number to ensure data is delivered to specific process

    connection oriented(TCP) -> requitr "handshake" to establish connection , ensure reliability

    Connectionless (UDP) -> send data immediately without a formal connection , faster but no

DATA FLOW IN OSI MODEL 

Application Layer: Applications create the data.
Presentation Layer: Data is formatted and encrypted.
Session Layer: Connections are established and managed.
Transport Layer: Data is broken into segments for reliable delivery.
Network Layer: Segments are packaged into packets and routed.
Data Link Layer: Packets are framed and sent to the next device.
Physical Layer: Frames are converted into bits and transmitted physically.
